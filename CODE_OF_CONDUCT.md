# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Expected behavior includes constructive technical discussion, inclusive language, respect for different experiences, and good-faith collaboration. Unacceptable behavior includes harassment, discrimination, personal attacks, deliberate intimidation, unwanted sexual attention, and publishing private information without permission.

Project maintainers may remove comments, close issues, or restrict participation when behavior violates these standards. Report concerns privately to the repository maintainers with the relevant links or context. All reports will be handled as confidentially as practical.
